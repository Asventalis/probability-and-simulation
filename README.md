# Probability and Simulation Notebooks

A collection of small, self-contained explorations in probability, combinatorics and stochastic simulation, mostly written to settle a question that came up in a game or a conversation. Each folder has its own README with the derivation, the method and how to run it.

| Folder | Topic |
|---|---|
| [`Cereal_Problem`](./Cereal_Problem) | Cereal Box Problem |
| [`secretary_problem`](./secretary_problem) | Secretary Problem |
| [`Poker_Polacco_probabilities`](./Poker_Polacco_probabilities) | Polish Poker Hand Probabilities |
| [`Risiko_probabilities`](./Risiko_probabilities) | Risiko Battle Probabilities |
| [`20_persone_a_coppie`](./20_persone_a_coppie) | Pairing 20 People |
| [`brownian_motion`](./brownian_motion) | Geometric Brownian Motion |
| [`simulated_2d_uniform_disk_walk`](./simulated_2d_uniform_disk_walk) | Uniform Disk Random Walk |
| [`uniform_sphere_distribution`](./uniform_sphere_distribution) | Uniform Points on a Sphere |
| [`Voronoi`](./Voronoi) | Moving Points Colour Field |

## Requirements
Python 3 with `numpy`, `scipy`, `matplotlib` (and Jupyter for the notebooks); the secretary problem and the sphere sampling are MATLAB scripts.
